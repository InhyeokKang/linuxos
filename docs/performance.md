# kiyu 성능 검토 — 크롬 RAM/CPU/GPU·4K 재생

윈도우에서 쓰던 크롬을 kiyu 에서 그대로 쓸 때, 전체 자원 사용이 줄어드는지 / 4K 가 원활한지에 대한 정리다.
숫자는 **일반적인 범위의 추정치**이며(하드웨어마다 다름), 실기기에서 `kiyu-perf-check` 로 직접 재는 방법을 함께 둔다.

## 요약
| 항목 | kiyu(XFCE) vs Windows 11 | 근거 |
|---|---|---|
| **전체 RAM** | **kiyu 가 크게 낮음** | 데스크톱 기본 점유가 확연히 작다. |
| **유휴 CPU** | kiyu 가 낮음 | 백그라운드 서비스/텔레메트리/인덱싱이 적다. |
| **4K 영상 CPU/GPU** | **설정하기 나름** | VA-API 하드웨어 디코드가 켜져야 원활. |

## 1) RAM — 왜 kiyu 가 유리한가
크롬 엔진(Chromium)은 OS 가 달라도 탭·프로세스당 메모리가 대체로 비슷하다. 차이는 **크롬이 아니라 그 아래 OS**에서 난다.
- Windows 11 유휴: 보통 **~2.5–4 GB** 점유(Defender·업데이트·검색 인덱싱·각종 서비스).
- kiyu(XFCE) 유휴: 보통 **~0.5–0.8 GB** (프리뷰 측정 기준 약 570 MB). XFCE 는 가장 가벼운 완성형 데스크톱 축에 든다.
- 결론: **같은 크롬 작업이라도 전체 시스템 RAM 은 kiyu 가 낮다.** 절약분(≈2 GB+)은 대부분 OS 기본 점유 차이에서 온다. 크롬 자체는 여전히 무거우니, 2 GB 기기에서 크롬 여러 탭+4K 는 어느 OS든 빠듯하다 — 다만 kiyu 는 그 여유를 더 준다.
- 더 가볍게: kiyu 기본 브라우저 **Taengja**(WebKitGTK)는 크롬보다 메모리를 덜 쓴다. 크롬이 꼭 필요할 때만 크롬을, 평소엔 Taengja 를 권장.

## 2) CPU
- **유휴**: kiyu 가 낮다(백그라운드 잡음이 적음).
- **4K 재생 중**: 전적으로 하드웨어 디코드 여부에 달림.
  - VA-API 하드웨어 디코드 O → CPU 낮게 유지(몇 %), GPU 비디오 엔진만 사용.
  - 소프트웨어 디코드 → CPU 여러 코어 급등, 저사양에선 프레임 드랍.

## 3) GPU·4K 유튜브 — 핵심 주의점
4K 유튜브는 **VP9 또는 AV1** 코덱이다. 원활하려면 **GPU 하드웨어 디코드(VA-API)** 가 필수인데:
- **크롬(리눅스)은 VA-API 가 기본 비활성**이라, 설정 없이는 4K 를 CPU 로 디코드 → 버벅임. `kiyu-setup-chrome` 가 필요한 플래그를 켜 준다.
- **GPU 자체의 코덱 지원 한계**도 있다:
  - VP9 하드웨어 디코드: Intel 9세대(Skylake)+ , AMD VCN, NVIDIA GTX 950+
  - AV1 하드웨어 디코드: Intel 11세대+, AMD RDNA2+, NVIDIA RTX 30+
  - 오래된 내장 GPU(= kiyu 의 주 타깃인 구형 기기)는 4K VP9/AV1 을 하드웨어로 못 풀 수 있고, 그러면 **1080p 가 현실적 한계**다. 이건 OS 문제가 아니라 GPU 한계 — 윈도우로도 똑같다.
- 정리: **최신~중급 GPU + VA-API 설정** → kiyu 에서 4K 원활(윈도우와 동급, CPU 는 오히려 낮게). **구형 저사양** → 4K 는 무리, 1080p 권장.

## 실기기에서 직접 측정 (내장 도구)
```sh
kiyu-setup-codecs      # VA-API 드라이버 + 코덱 (최초 1회)
kiyu-setup-chrome      # 크로미엄(권장) 또는 --chrome, VA-API 플래그 자동
kiyu-perf-check        # RAM/CPU/GPU/VA-API 상태 요약
kiyu-perf-check --watch  # 4K 영상 틀어놓고 CPU/GPU 부하 실시간 관찰
```
브라우저에서 `chrome://gpu` 의 **Video Decode = Hardware accelerated** 확인이 4K 하드웨어 디코드의 최종 판정이다.

> 이 문서의 표 수치는 추정 범위다. 정확한 비교는 위 도구로 같은 4K 영상을 kiyu 와 윈도우에서 각각 재보면 된다.
